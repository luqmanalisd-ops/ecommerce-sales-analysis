# E-Commerce Sales Analysis (Olist)

Analysis of the Olist Brazilian E-Commerce dataset (2016-2018): data cleaning,
sales analysis, 6 visualisations, a management dashboard and 5 business
insights.

## Files
- `e-commerce.ipynb` - full analysis (cleaning, 5 questions, 6 charts, dashboard, insights)
- `dashboard.png` - one-page management dashboard

## Tools
Python, pandas, matplotlib, seaborn (Kaggle notebook)

## Key findings
- Total revenue 13.22M BRL across 96,478 delivered orders
- Top category: health_beauty (1.23M BRL)
- Peak month: November 2017
- Southeast region generates 65% of revenue
- 79% of reviews are 4 or 5 stars

## How to run
Open the notebook on Kaggle with the Olist dataset attached and run all cells.
